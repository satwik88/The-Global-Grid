# Public APIs Rule

When tasked with finding, suggesting, or using a free API for a feature (e.g., news, weather, geocoding, authentication), you MUST ALWAYS consult the public APIs list stored locally at:
`.agents/resources/public-apis.md`

Use your `grep_search` or `view_file` tool on that file to find APIs in the relevant category. This repository is the authoritative source for free APIs on this system.
